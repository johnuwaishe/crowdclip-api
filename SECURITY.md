# Security policy

CrowdClip is an early-stage project and does not currently publish supported
release versions.

Please do not open a public issue for a suspected vulnerability or include
credentials, tokens, private media, or personal data in a report. Instead, use
GitHub's private vulnerability reporting feature on this repository. If that
feature is unavailable, contact the repository owner privately through their
GitHub profile.

Include the affected component, reproduction steps, impact, and any suggested
mitigation. You can expect acknowledgement when the report is reviewed, but no
fixed response or resolution timeline is promised while the project remains
pre-release.
